# Doc-Write

Doc-Write 是用于创作中文医疗小说的 Codex 技能。给它一个人物、一句设定或一章草稿，即可构思病房群像、撰写医院职场故事，或检查章节中人物的知情范围与病程时间线。

## 安装

在 macOS 或 Linux 终端中运行以下命令，将技能安装到当前用户的 Codex 技能目录。

```sh
mkdir -p ~/.codex/skills
git clone https://github.com/tianya023/Doc-Write.git ~/.codex/skills/doc-write
```

## 使用

在 Codex 中输入：

> 用 $doc-write 写一篇 1500 字的医疗短篇。主人公是一名即将出院的病人，他发现家人和医生对“回家”有两种不同的理解。从他收拾床头柜写起。

参阅[技能说明](SKILL.md)和[五种写法与原创示范](references/craft.md)。
